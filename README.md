# onesta-dist
ONEsta プラグイン 配布専用（Releasesのみ・ソース非公開）。各サイトの自動更新の取得先。

## 制作規約（AI・人 共通）

ONEsta / ONEstar 導入サイトで WordPress のコンテンツ（固定ページ・投稿・テンプレート・パターン）を作る・直すときの規約。ブロックだけで作り、カスタム HTML ブロック・`style` 属性・`<style>`・`<script>`・`<hr>`・spacer は使わない。

- 全文: [docs/ai-authoring-policy.md](docs/ai-authoring-policy.md)
- AI に渡す URL: `https://raw.githubusercontent.com/onesta385/onesta-dist/main/docs/ai-authoring-policy.md`
- 正本は onesta-core（ONEsta ZIP に同梱され、各サイトの `wp-content/plugins/onesta/docs/ai-authoring-policy.md` でも読める）
